# Jago Corporation PLC - Sales & Marketing Executive Management System

A Progressive Web Application (PWA) and Android Executive Portal for Jago Corporation PLC Water Purifier & Accessories Division.

## Features
- **Central Day Book**: Log daily collections, deliveries, cash custody, and pending orders.
- **Market Sales Reports**: Product sales summary, date-wise reports, customer summaries, and 3-month charts.
- **Customer Directory & Party Ledgers**: Complete customer accounts, opening balance logs, and statement vouchers.
- **Conveyance Bill & Report**: Route claim sheet generation and PDF vouchers.
- **Shareable Public View**: Password-free public viewing with Super Admin section access control (`?public_token=jagopublic2026`).
- **Offline & PWA Ready**: Installable on Android devices and PCs.

## Live Access & Deployment
- Web Application: Deployable on GitHub Pages, Netlify, cPanel, or InfinityFree.
- Android APK: Build via Capacitor (`npm run cap:sync`).
